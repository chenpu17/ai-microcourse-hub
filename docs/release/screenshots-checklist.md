# 使用截图清单

这份清单用于整理 GitHub README、Release 或作品集展示时需要的截图素材。

## 必备截图

### 1. 首页首屏

- 路径：`/`
- 重点：品牌氛围、主标题、报名入口、社区感视觉
- 建议比例：`16:10` 或 `1440 x 900`

### 2. 首页历史微课区

- 路径：`/`
- 重点：16 条以内卡片列表、分页、标签、卡片节奏
- 建议说明：突出“内容社区”而不是“课程后台”

### 3. 微课详情页

- 路径：`/micro-courses/[slug]`
- 重点：活动信息、多个资料链接、录播入口、相关推荐
- 建议截取：标题区 + 内容区同屏

### 4. 报名成功页

- 路径：`/success`
- 重点：成功状态反馈、统一视觉风格、下一步引导

### 5. 管理员后台 - 报名信息 tab

- 路径：`/admin`
- 重点：轻运营面板感、状态筛选、隐藏已完成报名

### 6. 管理员后台 - 历史活动 tab

- 路径：`/admin`
- 重点：表格化历史活动、主题 / 主讲人 / 日期时间 / 资料信息

## 可选加分截图

### 7. 报名浮层或报名入口交互

- 重点：免登录报名体验
- 适合用于强调“低门槛分享”

### 8. 管理员发布历史活动表单

- 重点：多资料链接、起止时间、编辑体验

### 9. 首页与详情页联动

- 重点：从列表卡片进入详情页的内容连续性

## 拍摄建议

- 使用统一数据集，避免不同截图信息风格割裂
- 桌面端统一宽度，避免 README 中图片比例忽大忽小
- 截图前确认字体颜色、按钮状态、空态提示都正常
- 如果公开展示，去掉任何可能映射到真实内部信息的内容
