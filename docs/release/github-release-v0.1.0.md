# AI 微波炉 v0.1.0

首个可演示版本已经准备好。

`AI 微波炉` 是一个面向内部 AI 学习氛围建设的微课社区：员工可以免登录报名分享主题，管理员可以轻量运营历史活动，团队成员可以查看微课详情、录播与资料链接，持续沉淀组织里的 AI 实践经验。

## 本次亮点

- 社区化首页与轻松、自然、活力的内容氛围
- 历史微课分页列表，单页最多展示 16 条
- 免登录报名与统一风格的成功反馈页
- 历史微课详情页，支持多个资料链接
- 管理员后台拆分为 `报名信息` / `历史活动` 两个 tab
- 历史活动表格化台账与 CSV 导出
- Prisma + SQLite + Playwright，可直接本地演示

## 适合场景

- 企业内部 AI 学习分享社区
- 研发团队午餐会 / 闪电分享 / 微课归档平台
- 需要快速验证“知识社区 + 轻运营后台”方向的产品原型

## 技术栈

- Next.js 15
- React 19
- Prisma
- SQLite
- Playwright

## 本地体验

```bash
npm run dev:up
```

默认地址：

- 首页：`http://localhost:3000`
- 后台：`http://localhost:3000/admin`
