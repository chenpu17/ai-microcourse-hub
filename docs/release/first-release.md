# AI 微波炉首个 Release 文案

建议版本号：`v0.1.0`

建议标题：

> `AI 微波炉 v0.1.0 · 首个可演示版本`

## Release 简介

`AI 微波炉` 的首个版本已经可用。它是一个面向内部学习氛围建设的 AI 微课社区：员工可以免登录报名分享主题，管理员可以轻量运营地沉淀历史活动，团队成员可以持续查看录播、资料链接和相关微课内容。

这次发布聚焦三个目标：

- 把分享门槛降下来，让愿意讲的人更容易报名
- 把历史经验沉淀下来，让 AI 学习不只停留在一次会后
- 把后台做得更轻，让运营动作像维护一个小社区而不是传统系统

## 本次版本亮点

### 1. 社区化首页体验

- 首页强调轻松、自然、活力的社区感
- 历史微课采用卡片化内容浏览
- 单页最多展示 16 条历史微课，支持翻页

### 2. 免登录报名流程

- 员工无需注册登录
- 只需填写议题、姓名、预计时长即可提交
- 提交后可看到统一风格的成功反馈页

### 3. 历史微课归档能力

- 支持发布历史活动主题、讲师、活动日期和起止时间
- 支持配置多个资料链接
- 支持详情页查看视频、资料与相关推荐

### 4. 轻运营后台

- 后台拆分为 `报名信息` 和 `历史活动` 两个 tab
- 支持表格化查看历史活动
- 支持标记和隐藏已完成的报名，减少运营噪音

### 5. 可直接落地演示

- 内置 Prisma + SQLite
- 提供 seed 数据
- 提供一键启动脚本
- 提供 Playwright 端到端测试

## 适合谁

- 想在公司内部推广 AI 使用氛围的团队
- 希望建立轻量知识社区的研发组织
- 想快速演示内部学习平台方向的产品 / 设计 / 工程团队

## 技术说明

- 前端：`Next.js 15`、`React 19`
- 数据层：`Prisma`、`SQLite`
- 测试：`Playwright`
- 启动方式：`npm run dev:up`

## 已验证项

- `npm run lint`
- `npm run build`
- `npm run test:e2e`

## 当前已知边界

- 资料链接为外部链接管理，不包含站内文件上传
- 当前数据库默认使用 `SQLite`，更适合演示与小范围试跑
- 管理员体系为轻量实现，正式环境建议接入公司 SSO
- 当前未做移动端适配

## 下一步 Roadmap

- 接入正式内网鉴权
- 升级数据库到 `PostgreSQL`
- 增加运营数据分析与趋势看板
- 支持更完整的活动状态流转
